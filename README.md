# 阴阳师手帖 v4

## 部署
将本目录内容上传至 GitHub Pages 项目仓库根目录（若使用项目路径 `/onmyoji-tracker/`，保持仓库目录结构不变）。

## 本地数据与升级
第四版继续使用第三版的 localStorage key：`onmyoji_tracker_v1`。首次打开会在原数据上增量初始化 v4 字段，并把旧版综合资源快照拆分到「勾玉 + 符咒」和「体力」两组历史中；第三版账号、任务、打卡和当前资源不会主动清除。建议升级前先在第三版导出 JSON 备份。

## 资源规则
三组独立保存：勾玉+符咒、体力、魂玉。只清空本组输入框。魂玉累充显示「累计充值」（只累加充值）和「魂玉净额」（充值减消费），记录独立于游戏魂玉数量。

## 说明
所有数据默认保存在当前浏览器本地，不会自动云同步。请定期导出 JSON 备份。
